## 📌 Overview

This project presents a Deep Learning-based system for detecting and grading **Diabetic Retinopathy (DR)** from retinal fundus images using Convolutional Neural Networks (CNN).

Diabetic Retinopathy is a diabetes complication that affects the eyes and can lead to blindness if not detected early. This system aims to assist medical professionals by automating the screening and classification process.

---

## 🎯 Objectives

- Develop a CNN-based model for retinal image classification
- Detect and classify the severity level of Diabetic Retinopathy
- Improve early diagnosis through automated screening
- Evaluate model performance using medical evaluation metrics

---

## 🧠 Methodology

1. **Data Preprocessing**
   - Image resizing and normalization
   - Data augmentation to improve generalization
   - Train-test split for evaluation

2. **Model Development**
   - Convolutional Neural Network (CNN)
   - Transfer Learning with pretrained models
   - Fine-tuning for medical image classification

3. **Model Evaluation**
   - Accuracy
   - Precision
   - Recall
   - F1-Score
   - Confusion Matrix
